Soroban contracts, a typed SDK ([`@bound/sdk`](https://www.npmjs.com/package/@bound/sdk)) and an MCP connector ([`@bound/mcp`](https://www.npmjs.com/package/@bound/mcp)) on Stellar. Started at ETHGlobal Cannes 2026 as [CCP](https://github.com/iamnotdou/ccp) on Hedera. [repo](https://github.com/iamnotdou/bound) · [docs](https://docs.boundprotocol.dev)
- **[Xora](https://xora.social)** - Hybrid social network that brings Web2 users on-chain: every account gets an MPC wallet at sign-up, no seed phrases. Built on Chopin Framework with Celestia for data availability. Celestia Mammothon 2025 finalist. [repo](https://github.com/miragelabs-dev/xora)
- **[Sticket](https://github.com/iamnotdou/sticket-contracts)** - Decentralized NFT ticketing marketplace on Soroban with factory-deployed events, resale controls and creator royalties.
